Harbor City: Sun, Salt & Sirens — a complete 2D top-down open-world crime game in a sun-soaked coastal city, built with vanilla JavaScript on canvas and no libraries, no external assets, and no network requests. Explore the city on foot or by stolen car, dodge traffic and pedestrians, earn a wanted level and outrun the police, fight with fists and a pistol, and work through a five-mission story for cash. The game runs entirely offline from static files: serve the game/ folder and open index.html in a desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Controls: WASD to move or drive, mouse to aim, click to shoot, F to punch, E to enter or exit a car, R to reload, Space for the handbrake, P or Esc to pause, H for help.
